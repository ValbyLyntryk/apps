Read archived mail in place

Point this program at the folder of .eml files on your network drive. Files stay where they are. Search, tags, and stars live in archive.db next to this program, so every PC that launches the same .exe shares the index.

  • Search: invoice from:billing after:2023-01-01
  • Organize with tags and stars — nothing is moved
  • Open attachments from the original file

Try it first with sample messages: python3 email_archive.py --demo
